# Voxora

**Connect. Chat. Play.**

Voxora is a community chat platform project inspired by Discord.

## About

Voxora is being developed as a web-based place for communities to connect and chat. The project is currently under development.

## Built with

- Cloudflare Workers
- Cloudflare D1
- HTML, CSS and JavaScript

## Status

Voxora is a work in progress. Some features shown in the interface may be demos and may not yet store data or work as production features.
